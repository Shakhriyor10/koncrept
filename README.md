# Koncrept — продажа билетов на концерт

Минималистичное Django-приложение для концерта Эльдара Далгатова. Покупатель регистрируется, выбирает категории и количество билетов, переводит оплату по реквизитам организатора и отправляет чек. Администратор сверяет перевод вручную; после одобрения приложение выпускает отдельный QR-билет на каждое место в заказе.

## Возможности

- Регистрация, вход по номеру телефона Узбекистана (+998 и 9 цифр) и личный кабинет с заказами.
- Типы билетов VIP, стандарт и фан-зона; цены настраиваются в админке.
- Карты HUMO и UZCARD управляются в админке. Покупатель видит только активные карты.
- Защищённая загрузка чеков JPG, JPEG, PNG, WebP, BMP, TIFF, HEIC/HEIF и PDF (до 10 МБ). Файлы доступны для скачивания только сотрудникам сайта.
- Проверка чека администратором: одобрение выдаёт по одному QR-билету на каждый оплаченный билет; отклонённый чек можно отправить повторно.
- После одобрения покупатель может скачать один PDF-файл с отдельной страницей билета и QR-кодом для каждого купленного билета.
- Таймер проверки на 15 минут и автоматическое обновление статуса заказа без перезагрузки страницы.
- QR-билет можно распечатать; страница проверки показывает действительность билета и факт прохода.

Переводы подтверждаются вручную. Приложение не подключено к банковскому API и не может автоматически проверить поступление денег.

## Локальный запуск

Нужен Python 3.10 или новее.

### Windows PowerShell

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```

### Linux

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`, админку — `http://127.0.0.1:8000/admin/`. При первой миграции создаются концерт 25 октября 2026 года и три категории с заданными ценами.

В админке создайте карту в разделе «Карты для перевода» и включите флаг «Активна». Заказы и чеки проверяйте в разделе «Заказы»; файл чека можно скачать только из админки. Для одобрения выберите заказ со статусом «Проверка оплаты» и примените действие «Одобрить чек и выдать билеты».

## Переменные окружения

Скопируйте `.env.example` в `.env` или задайте значения в окружении службы:

- `DJANGO_SECRET_KEY` — случайный секрет для сессий и CSRF.
- `DJANGO_DEBUG=0` — обязательно для production.
- `DJANGO_ALLOWED_HOSTS` — домены сервера через запятую.
- `DJANGO_CSRF_TRUSTED_ORIGINS` — HTTPS origins, через запятую.
- `DATABASE_URL` — необязательный PostgreSQL URL. Без него используется SQLite.
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_WEBHOOK_SECRET` — для уведомлений о переводах и решений по заказам из Telegram.

### Telegram-проверка оплат

Добавьте бота в закрытую группу проверки оплат и назначьте его администратором: это нужно, чтобы бот мог проверить права нажатия кнопки через Telegram. В `.env` укажите токен бота, ID группы (обычно отрицательное число) и случайный `TELEGRAM_WEBHOOK_SECRET`. `PUBLIC_SITE_URL` должен вести на доступный Telegram HTTPS-адрес. Затем выполните `python manage.py set_telegram_webhook`. Заказы появятся в группе с данными покупки, чеком при его наличии и кнопками одобрения/отклонения; нажимать их смогут только администраторы группы.

Перед публичным запуском задайте собственный секрет, отключите debug, выполните миграции и `collectstatic`. Gunicorn должен запускать `koncrept.wsgi:application`; Nginx направляет приложение в Gunicorn, отдаёт `/static/` из `staticfiles/` и ограничивает загрузки размером 12 МБ. Папку `private_uploads/` нельзя публиковать напрямую: чек отдаётся через авторизованный маршрут администратора.

Для генерации PDF с кириллическим текстом на Debian/Ubuntu установите системный шрифт: `sudo apt-get install fonts-dejavu-core`.

В каталоге `deploy/` находятся пример systemd-службы и Nginx-конфигурации для VPS. В службе приложение слушает приватный Unix-сокет; порт `8068` перенаправляет посетителя на HTTPS-домен, чтобы вход и сессии не шли по незащищённому HTTP. Перед включением конфигурации выпустите сертификат Let's Encrypt для `majormotors.uz` и `www.majormotors.uz`.
